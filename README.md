# astrbot_plugin_food_ledger

一个给 AstrBot 用的餐饮记账插件。

家里开了个餐饮店，每天进货、日常开销、外卖平台的流水太杂了，专门给店里做了个记账机器人：直接把账单截图或者一句话丢给它，它会自己识别金额和分类，先给我看一眼确认没问题再入库。店里几个人都能在群里记，月底查账一目了然。

## 功能

- **发图片就自动记账**，不用输任何指令（店里人直接把截图丢群里就行）
- 文字、图片账单都能识别（图片走「图片转述模型」转成文字，再由「解析模型」整理成账目）
- 两个模型可以分开选：图片转述模型选个支持视觉的，解析模型随便用个 LLM 就行
- 识别结果**先给你审查**，可以改金额/类别/描述，确认之后才写进数据库
- 每条记录都带记账时间，查账按时间排序，明细精确到几点几分
- 查账支持按天、按月、按类别统计
- 数据存 SQLite，放在 AstrBot 的 `data/plugin_data/astrbot_plugin_food_ledger/` 下，卸载重装都不丢
- 基于 AstrMessageEvent 抽象层写的，所有消息平台都能用

## 安装

1. 整个目录扔到 AstrBot 的 `data/plugins/` 下（目录名保持 `astrbot_plugin_food_ledger`）
2. WebUI 插件管理里重载一下
3. 进插件配置，选一下「图片转述模型」和「账单解析模型」
4. 完事，没有第三方依赖

需要 AstrBot >= 4.16。

## 识别流程

```
图片账单 ──► 图片转述模型（视觉模型，OCR 出文字）──► 文字描述
                                                       │
文字账单 ──────────────────────────────────────────────┼──► 解析模型（LLM）──► 结构化账目 ──► 审查 ──► 确认入库
```

- 图片转述模型没配的话，会退化成让解析模型直接看图（如果它支持多模态的话）
- 纯文字账单就只调一次解析模型

## 指令

所有指令都有英文/别名版本，比如 `/ledger 查账 本月`、`/账本 记 午餐 25 元`。

| 指令 | 说明 |
| --- | --- |
| （无指令）直接发账单截图 | **自动识别记账**，最常用 |
| `/记账 记 <文字或图片>` | 手动记账，支持纯文字 |
| `/记账 确认` | 确认当前草稿，入账 |
| `/记账 修改 <序号> <金额\|类别\|描述> <新值>` | 改草稿，比如 `/记账 修改 1 金额 15` |
| `/记账 取消` | 放弃草稿 |
| `/记账 查账 [今天\|昨天\|本月\|上月\|日期\|日期 日期] [类别]` | 查账 |
| `/记账 类别 [添加 xxx]` | 管理类别 |
| `/记账 帮助` | 使用说明 |

模型不用指令设置，在 WebUI 插件配置里选就行。

## 使用示例

```
（先在插件配置里选好两个模型）
你：（把外卖截图直接丢群里，什么字都不用打）
Bot：📋 待确认账单（共 2 笔）｜08-12 13:42
     1. 外卖｜33.80 元｜炸鸡套餐
     2. 饮品｜12.00 元｜可乐
     💰 合计：45.80 元
     ✅ 回复「/记账 确认」入账
     ✏️ 修改：「/记账 修改 1 金额 15」……
你：/记账 确认
Bot：✅ 已入账 2 笔，共 45.80 元（2026-08-12，08-12 13:45 记）
```

群里其他人发账单截图也一样，谁发都行；确认后查账：

```
你：/记账 查账 本月
Bot：📊 餐饮账目统计
     📅 2026-08-01 ~ 2026-08-12
     💰 总支出：246.30 元（18 笔）
     🗂️ 按类别：
     · 外卖：88.90 元（5 笔）
     · 早餐：45.50 元（7 笔）
     ...
     📋 明细：
     #1 08-12 13:42 外卖 33.80 炸鸡套餐
     #2 08-12 08:15 早餐 8.50 包子
     ...
```

## 配置项

| 配置 | 说明 |
| --- | --- |
| 图片转述模型 | 把账单图片转成文字，选支持视觉的模型；留空则用解析模型直接看图 |
| 账单解析模型 | 把文字整理成账目；留空则用当前会话的模型 |
| 图片压缩最长边 | 转述前把图片最长边压到该像素（默认 768）。微信截图原图很大，不压缩会把小模型的 context 撑爆（如 2k 上下文装不下） |
| 图片压缩质量 | JPEG 质量 1-100（默认 80） |
| 类别列表 | 逗号分隔，识别结果归入这些类别，匹配不上的进「其他」 |
| 自动识别图片账单 | 收到带图片的消息自动尝试记账（默认开）；关掉后只能手动发 `/记账 记` |
| 单次最多记录条数 | 防止模型抽风输出一堆条目（默认 20） |
| 金额单位符号 | 查账展示用（默认「元」） |

## 已知问题

- WebUI 的模型下拉框会把所有聊天提供商都列出来，**没法自动区分哪个支持视觉**，选图片转述模型的时候需要自己挑支持图片输入的（Qwen-VL、GPT-4o 这种）
- 自动识别是"尽量识别"：图里没有账单内容时会静默放行，交给 AstrBot 正常聊天；但如果图片里恰好有金额数字，有可能被误当成账单——识别结果反正要人工确认才入库，问题不大。不想要这个行为就关掉「自动识别图片账单」
- 查账明细目前只显示最近 200 条（TODO：之后加分页）
- 图片识别效果取决于选的视觉模型，识别不准的话改一下模型或者手动改草稿都行
